
# Retail Return Policy

Category: Returns
Document ID: RET-001
Version: 1.0

## Return Eligibility

Customers may request a return for eligible products
within the applicable return window.

## Return Conditions

- Product must meet the applicable return conditions.
- Proof of purchase may be required.
- Some product categories may have different conditions.

## Return Process

1. Open the order details.
2. Select the eligible item.
3. Choose the return option.
4. Follow the return instructions.

## Exceptions

Some products may have special return restrictions.
Check the applicable product category policy before
confirming eligibility.
